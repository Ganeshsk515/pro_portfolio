# Professional Portfolio

A clean and modern portfolio template built for interview-ready presentation. Customize the content and replace placeholder text with your personal details, projects, skills, and contact information.

## Files

- `index.html` — homepage introduction
- `about.html` — about page
- `projects.html` — portfolio work
- `skills.html` — skills and expertise
- `contact.html` — contact page
- `styles.css` — responsive styling and layout
- `script.js` — navigation behavior and resume link

## Customize

1. Open `index.html`.
2. Replace `Your Name` with your full name.
3. Update the section copy under About, Projects, Skills, and Contact.
4. Replace the resume link in `script.js` with your actual resume URL.

## Preview locally

Open `index.html` in your browser to view the portfolio.

## Notes

- Use your real project case studies and metrics to impress interviewers.
- Keep the content concise, polished, and outcome-focused.
- Use a high-quality photo or illustration in the `profile-photo` section if you want a more personal look.
